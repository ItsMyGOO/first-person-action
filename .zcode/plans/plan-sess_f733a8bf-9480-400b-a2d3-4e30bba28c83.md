# M3(修订版) 实施计划：技能框架 + 战士kit + 弓箭手瞄准状态机 + 逻辑空间阻挡 + 简易选人

## 范围
1. **逻辑空间系统**（阵型文档5/6/19/20节）：SpatialResolver 纯逻辑（半径重叠 + 质量比分摊 + PushForce挤开 + 豁免标志）+ SpatialSystem 每帧回场应用（MoveAndCollide 尊重墙体）；玩家↔敌人由逻辑系统接管，物理掩码只留世界层
2. **技能框架**：SkillDefinition(Resource) + Ability 基类（CD/阶段/取消）+ IAbilityContext 统一接口 + ForcedMovement 强制位移纯逻辑
3. **战士kit**：跳劈（弧线+落地AoE+击退+霸体）、冲锋（接挤开规则：轻单位被推、重单位挡停）、旋风斩（360°填充技）
4. **弓箭手**（消逝的光芒式）：右键按住=瞄准（肩视/FOV65/移速×0.5），左键按住=蓄力（3级），松开左键=按等级射箭（Area3D投射物）；非瞄准左键=快速弱箭；**技能/闪避打断瞄准+蓄力（不放箭）**；弓手带1个后跳技验证打断
5. **角色数据化+选人**：CharacterDefinition(Resource)（战士/弓箭手 .tres）+ GameSession(autoload) + 启动选人界面（两按钮）；加角色不改控制器
6. **HUD**：准星 + 蓄力条（占位样式）

**不做**：处决(M4)、刺客、敌人AI/阵型、网络传输、正式动画。

## 任务序（每步构建+测试，独立提交，最后合并）
- **A 逻辑空间**：SpatialBody/SpatialResolver 纯逻辑（TDD，含文档第20节数值例）→ SpatialAgent 扩展（组注册/OwnerBody/CurrentMovementForce）→ SpatialSystem 节点 → 物理掩码调整 → 木桩强制位移通道
- **B 控制器重构**：Player 动作层显式状态机（None/Melee/Dodge/Skill）+ 输入改为物理帧边沿轮询（模拟与联机友好，行为等价迁移）
- **C 技能框架+战士kit**：ForcedMovement/Ability/SkillDefinition/工厂 + 四个技能 + CharacterDefinition/GameSession + 输入映射(Q/E/R) + 角色.tres
- **D 弓箭手**：ChargeAccumulator 纯逻辑（TDD）+ Projectile 箭矢 + 瞄准/蓄力状态机 + 打断规则 + HUD
- **E 选人流程**：CharacterSelect 界面 + Main 按定义生成玩家 + 主场景切换
- **F 验收合并**：引擎冒烟测试扩写（阻挡/冲锋推挤/重单位挡停/旋风/跳劈/弓手三态+打断/两角色流程）+ 全量测试 + csharpier + 合并 main + 更新规格里程碑

## 验收
玩家无法穿过木桩（停在半径和）；冲锋推开普通木桩、被重木桩挡停；战士三技能CD独立可放；弓手瞄准/蓄力/放箭三级伤害正确且技能闪避可打断（不放箭）；选人两角色均可进入作战；全部单测+无头冒烟通过。
