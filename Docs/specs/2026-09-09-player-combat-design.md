# 玩家侧战斗系统设计（v1）

> 文档定位：玩家侧系统（角色控制器 / 技能框架 / 处决 / 联机约定）的规格说明。
> 前置文档：[第一人称战术阵型战斗：敌方前后排与空间突破系统](../../Docs/formation-combat-design.md)（下称"阵型文档"）。本系统与阵型系统最终拼合，v1 先做玩家侧。

---

## 0. 已确认的决策

| 主题 | 决策 |
|---|---|
| 视角/操作 | 第一人称，龙之谷式操作（连段普攻 + CD 技能 + 闪避无敌帧），软锁定，攻击朝向跟随镜头 |
| 控制器深度 | 打击状态版：连段/CD技能/闪避 + 敌人受击状态（硬直/击退/倒地/失衡）。取消窗口、方向派生、空中连段留到后期 |
| 处决 | Doom 式按键处决，短演出，**不允许明显吸附**（双向缓动收敛 + hit-stop 遮罩） |
| 技能原型 | 战士跳劈（强制位移+AoE+击退）、弓手瞄准状态（镜头状态+蓄力）、刺客疾行/穿人（冲刺+空间豁免） |
| 联机 | 2~4 人 PvE 合作，房主权威 listen server，状态级同步。接口从第一天预留，v1 单机可玩 |
| 切入顺序 | 玩家侧优先；敌人先用木桩/简单敌人验证手感，之后再接阵型 MVP |
| 架构 | 代码状态机为真相源 + 数据驱动 Ability，动画（AnimationTree）只做表现跟随；吸收节点/Resource 组合性 |

## 1. 分层与数据流

```text
PlayerInput（设备原始输入）
    ↓
InputCommand（语义命令 + 输入缓冲）        ← 联机边界在这里
    ↓
CharacterController（分层状态机，唯一真相源）
    ↓ Ability 通过统一接口请求：切状态 / 强制位移 / 判定窗口
Movement Pipeline（Normal → Forced → Spatial Resolution）  ← 对接阵型文档第 25 节
    ↓
SpatialAgent（半径/质量/豁免标志）
    ↓
Presentation（AnimationTree 跟随、镜头、VFX、音效 —— 只读状态，永不驱动逻辑）
```

核心原则：

- **逻辑永远不等动画**。连段进度、CD、霸体、取消窗口全部是代码状态；占位阶段用代码位移 + hit-stop + 震屏调手感，动画到位后 AnimationTree 只做表现。
- **联机透明**：单机命令本地执行，联机命令发房主权威；控制器不感知差别。

## 2. 角色与技能数据模型

- **`CharacterDefinition`（Resource）**：角色 ID、显示名、属性（HP/移速/GameplayMass/PushResistance）、技能槽列表（技能 ID → Ability 类型 + SkillDefinition）、FP viewmodel 与全身模型引用。加角色 = 加 `.tres` + 技能组合，不改代码。
- **`SkillDefinition`（Resource，纯数据）**：CD/消耗；施放类型（瞬发/引导/蓄力/开关状态）；三阶段时长（前摇/主动/后摇）；判定窗口（形状 + 伤害 + 韧性伤害 + 受击效果）；强制位移曲线（冲刺/跳跃弧线）；标志位（穿人/霸体/无敌帧）；取消规则（可被哪些输入打断哪个阶段）。
- **Ability 运行时类**：每技能一个实例，管理 CD 与阶段推进，通过控制器统一接口执行。v1 三个原型各对应一个实现：
  - `LeapSlamAbility`：跳跃弧线强制位移（期间霸体）+ 落点 AoE + 击退——跳过前排砸缺口的突破手段；
  - `AimModeAbility`：进入/退出瞄准状态（肩视镜头、移速下降），蓄力等级决定投射物威力；
  - `DashPhaseAbility`：冲刺位移 + 空间豁免标志（对单位无碰撞、对地形仍有碰撞）。

战士 v1 kit 为三个技能：跳劈、冲锋、一个填充技。其中**冲锋（`ChargeAbility`）**：直线快速位移，通过 GameplayMass/PushForce 机制推开路径上的轻型单位、被重型单位阻挡（阵型文档第 6 节挤开规则），是"挤开"玩法的玩家侧入口。 assassin 的 DashPhase 与之的区别：冲刺更短更快、带空间豁免（穿过而非推开）、通常附带无敌帧。

## 3. 控制器状态设计

两层状态机：

- **移动层**：Grounded / Airborne / AimMode；
- **行动层**：Idle / Combo 第 N 段 / SkillCast / Dodge / Execute / Staggered。

行动层压制移动层（Execute/SkillCast 期间移动输入转为一阶缓动或忽略，按技能数据定义）。普攻连段表 3~4 段；输入缓冲约 150ms；段与段之间有取消窗口（可接技能/闪避）。

相机：FP 主相机 + FP 手臂 viewmodel；完整身体模型保留（供投影与队友视角），本地视角隐藏头部防穿模（Vermintide 式做法）。

## 4. 打击判定与受击状态

- **判定**：主动帧窗口内做形状查询（球形/胶囊扫掠），无常驻近战碰撞体（确定性强、联机友好）；投射物才用 Area3D。
- **受击状态机**（敌人侧，阵型系统直接复用）：正常 → 硬直（Stagger）→ 击退（Knockback）→ 倒地（Downed）→ 失衡可处决（Executed 状态除外）。由**韧性值**驱动：攻击带韧性伤害，清零触发倒地；阈值由敌人定义。
- **Hit-stop 管理器**：命中重击时全局时间缩放 60~90ms——既是手感核心，也是处决修正的遮罩。

## 5. 处决流程

**可用条件**：敌人处于可处决状态（倒地/失衡）且位于玩家前方约 45° 锥形 + 0.8~1.8m 距离带 → HUD 提示按键。

**触发后四步**：

1. **锁定**：玩家 → Executing，敌人 → Executed；双方 AI 暂停、免疫外部伤害；空间系统对这一对豁免（阵型文档第 21 节"强制位移可暂时突破空间规则"的自然延伸）；
2. **收敛**：150~250ms 双向缓动——玩家上步约 35%、敌人靠拢约 65%，无瞬移、无可见吸附；
3. **冲击**：hit-stop + 震屏 + 致命一击（占位期：viewmodel 挥动 + 敌人程序化跪倒）；
4. **结算**：敌人死亡（后期换 Ragdoll/溶解），玩家获得奖励（回血 %），回 Idle；输入缓冲在锁定瞬间清空。

**边界情况**：收敛途中目标被队友击杀 → 干净中止、无奖励；冲刺穿人结束时停在敌人半径内 → 由空间解析器温和推出（阵型文档第 19 节）。

## 6. 联机预留约定（代码规范，第一天生效）

1. 所有战斗实体持 `NetworkId`，模拟层只按 ID 引用实体；
2. 无全局 Player 单例，只有"本机控制的角色"间接层；
3. 玩家输入一律先转 `InputCommand`（可序列化结构体）再进入控制器；单机本地执行，联机发房主；
4. 随机数用带种子的独立实例，禁用全局 RNG；
5. 表现层只订阅状态，不回写模拟；
6. 同步模型：房主权威 + 状态级同步（技能施放事件 + 位置快照插值），不做逐帧同步，不做客户端预测（PvE 合作不需要）。

## 7. 里程碑与验收标准

| 里程碑 | 内容 | 验收 |
|---|---|---|
| M1 | 输入/命令层 + 移动跳跃 + FP 相机 + 木桩敌人 | 移动/转向跟手 |
| M2 | 3 段连击 + 判定窗口 + hit-stop + 敌人受击状态 | 连段不丢输入；倒地可观察 |
| M3 | 技能框架 + 战士 kit（跳劈/冲锋/旋风斩）+ 闪避无敌帧 | 冲锋推散木桩群；跳劈范围击退 |
| M4 | 处决雏形 | 倒地敌人处决全流程，看不出吸附 |
| M4 修订 | （2026-09-09 修订并完成）敌人 AI（远程/护卫/低级兵，单体+群体）+ 战斗手感打磨（冲锋速度感/跳劈力量感/落地重量感）+ 技能改键底层 + 箭矢方向修复；处决/刺客顺延 | 转身 180° 射箭命中；敌箭/近战使玩家掉血、死亡重载；键位重绑持久化；低级兵环绕、护卫贴翼推不动、远程 7~11m 风筝；落地震动+下沉+110ms 顿帧+冲击波环；单测 59 + 冒烟 35 全过 |
| M5 | 第二角色（弓箭手：瞄准/三级蓄力/打断规则）+ 逻辑空间阻挡 + 选人界面 | 换角色不改代码；玩家被敌人挡停在半径和；冲锋推轻挡重（2026-09-09 修订：弓手按用户要求提前，刺客顺延至 M5 之后） |

| M5 阵型 | （2026-09-10 完成计划 2026-09-10-m5-formation-mvp-speedlines）阵型文档 §23 MVP：3 前排（盾 250 可推/骑士 500 不可推）+ 2 后排（弓/法）、槽位驻守、朝向滞回 55°、死亡开缺口不补位、后排压制 + 冲刺速度线 shader（径向线条+暗角，CameraFeel 混合度驱动） | 正面被前排挡停；击杀中排缺口可穿；阈值内绕阵不跟转；后排箭掉血；冲锋推散 250 盾/被 500 骑士挡停；贴侧蹭血；冲锋全程速度线强度 >0.5、结束 0.5s 回落 <0.05；单测 71 + 冒烟 53 全过 |

| M6 处决 | （2026-09-25 补齐 M4 顺延项）处决全流程：45° 锥形 + 0.8~1.8m 距离带谓词（ExecutionQuery 纯逻辑单测）/ HUD 按键提示（跟随实际绑定键）/ 锁定-收敛-冲击-结算四步（0.20s 双向缓动 35/65 分摊、150ms 顿帧+震屏、回血 15% 最大生命）/ 收敛途中外部击杀干净中止 / 空间系统对处决双方豁免 | 击倒后带内提示、背向/超距不提示；收敛无瞬移（单帧位移 <0.15m）；处决击杀 + 回血 108（90+18）；单测 86 + 冒烟 76 全过 |

| M7 刺客 | （2026-09-25 完成）刺客原型：Assassin.tres（100HP/5.6 移速/疾行+后跳，选人界面自动出现——数据驱动闭环）+ DashThroughAbility 疾行（7m/0.30s，IAbilityContext.SetSpatialExempt 空间豁免穿人，对照冲锋的推挤/挡停；打断/收尾路径统一清豁免）+ IsDashing 冲刺表现泛化（冲锋/疾行共享 FOV 拉伸+抖动+速度线） | 穿人冲刺 7m 未被挡停、路径单位位移 <0.3m（穿而不推）；疾行速度线 >0.5；后跳 2.5m；刺客普攻复用连段命中；单测 88 + 冒烟 90 全过 |

弓手瞄准状态排在 M5 之后或替换刺客（若优先验证镜头状态机）。阵型系统 MVP 已于 2026-09-10 接入完成（复用 SpatialAgent 与受击状态）。

## 8. 目录结构与测试

```text
Game/Gameplay/
├── Core/      （实体ID、种子RNG、InputCommand 定义）
├── Combat/    （控制器、Ability、判定、受击、处决、hit-stop）
├── Characters/（角色定义、选人）
└── Spatial/   （SpatialAgent，未来阵型共用）
Game/Config/   （角色/技能 .tres）
Game/Scenes/   Game/UI/  Tests/
```

测试：xUnit 单测覆盖连段状态机转换、缓冲窗口、CD、处决触发谓词（锥形/距离）、Command 序列化往返；每个里程碑配一份手工手感清单（手感无法自动化）。

## 9. 非目标（v1 明确不做）

- 取消窗口表、方向派生技、空中连段（后期目标）；
- 客户端预测/回滚、专用服务器、大厅系统；
- 阵型 AI、Formation Slot（阵型文档范围，后续接入）；
- 正式动画/Ragdoll 资产（占位资产 + 程序化表现）。
